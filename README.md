A chess engine in 4,080 bytes of Python 3.13 standard library: 0x88 board, negamax alpha-beta with quiescence search and a transposition table, tapered piece-square evaluation. Practice Elo 1451 on the kit gauntlet (three 6-game trials: 1451/1451/1451).

## Run it

```sh
MAKEFUN_ENV_URL=<env url> python3 -P -s main.py
```
